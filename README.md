Открытие отсутствующего файла вызывает `FileNotFoundError`, который оболочка

и UnicodeDecodeError, в конвертере — FileNotFoundError и ValueError.
Общего обработчика OSError нет. Перехваченные ошибки выводятся без traceback,
через stderr; `parser.error()` печатает справку по использованию и завершает программу с кодом 2.
Успешная команда и `--help` завершаются с кодом 0.

### Подготовка к защите

**Что сделано?** Две CLI-оболочки: argparse разбирает команды, затем вызываются
функции прошлых лабораторных. CLI — Command Line Interface, интерфейс командной строки.

**Почему команда преподавателя неверная?**

```powershell
py -m src.lab06.cli_text --input data/lab06/samples/stats.txt cat
```

`--input` зарегистрирован у парсера подкоманды, а не у общего парсера.
Сначала нужно выбрать `cat`, а затем передать его параметры:

```powershell
py -m src.lab06.cli_text cat --input data/lab06/samples/stats.txt
```

Это следствие структуры наших парсеров, а не универсальный запрет на параметры
перед подкомандой: у других CLI могут быть общие параметры перед ней.

**Почему можно вывести исходный код?** Файл с расширением `.py` — текстовый файл.
`cat` не проверяет расширение и не исполняет содержимое: `open(..., encoding="utf-8")`
читает строки, `print` выводит их. Наши исходники сохранены в UTF-8.
В Python 3 UTF-8 — стандартная кодировка исходного кода; но кодировка произвольного
текстового файла не обязана быть UTF-8, поэтому при чтении она указана явно.

```powershell
py -m src.lab06.cli_text cat --input src/lab06/cli_text.py -n
```

**Что такое `-m`?** Запуск модуля по имени в структуре пакетов.
Он позволяет использовать импорты `from src...`, когда команда выполняется из корня проекта.
В имени модуля точки вместо слешей, расширение `.py` не пишется.

**Что делает `parse_args()`?** Читает аргументы командной строки и возвращает Namespace.
Для `stats --input ... --top 3` получаем `args.command == "stats"`,
путь в `args.input`, целое число 3 в `args.top`.

**Зачем `dest`?** Задаёт имя атрибута Namespace. У подкоманд это `command`.
Для `--in` указано `dest="input"`, потому что `in` — ключевое слово Python
и выражение `args.in` синтаксически недопустимо.

**Что проверяет `required=True`?** У subparsers — наличие подкоманды,
у аргумента — наличие этого параметра. Отсутствующие значения обрабатывает argparse.

**Чем флаг отличается от параметра со значением?** `-n` не принимает значение,
а просто включает нумерацию. `--input` принимает путь, `--top` принимает целое число.
Здесь `-n` — флаг, а не позиционный аргумент.

**Зачем `if __name__ == "__main__"`?** Вызывает main только при запуске модуля.
При импорте можно использовать функции без запуска CLI и разбора чужих аргументов.

**Как считаются слова?** normalize → tokenize → count_freq → top_n.
Всего слов — длина списка токенов, уникальных — длина словаря частот.
Сортировка по `(-count, word)` даёт частоту по убыванию и слово по возрастанию.

**Что занимает память?** `cat` читает весь текст через read_text и создаёт список строк.
`stats` тоже читает весь текст, создаёт токены и словарь, затем сортирует уникальные слова.
Топ-N не означает, что читаются только N слов.

**Зачем `with`?** Файл закрывается при выходе из блока, в том числе при исключении.

**Почему возраст в JSON строкой?** CSV не хранит типы ячеек; csv.reader возвращает строки.
Самостоятельно угадывать типы конвертер не должен.

**Почему XLSX работает без Excel?** Книгу создаёт библиотека openpyxl;
устанавливать сам Excel для конвертации не требуется. Без openpyxl текущий
XLSX-конвертер не работает. XLSX хранит XML-документы внутри ZIP-архива.

**Что показать преподавателю?** Запустить `cat -n`, `stats --top 3`, три конвертации,
справку, ошибку отсутствующего файла и ошибку `--top abc`. Затем исправить порядок
аргументов в его примере и вывести собственный исходник через `cat`.

## Задание 1 - Нормализация текста

Функция normalize приводит строку к единому виду: нижний регистр, ё заменена на е, лишние пробелы убраны.

Сначала проверяем, что на входе строка, иначе TypeError. Дальше через if-else приводим текст к нижнему регистру: casefold() или lower(), в зависимости от флага casefold. Если включен yo2e, заменяем ё на е через .replace(). В конце text.split() без аргументов сам режет строку по любым пробельным символам (\t, \r, \n и повторяющимся пробелам), а " ".join() склеивает слова обратно через один пробел, так что края заодно обрезаются. Флаги casefold и yo2e именованные (после *).

Файл: src/lib/text.py

## Задание 2 - Токенизация

Функция tokenize достает из текста слова: буквы, цифры, подчеркивание, а дефис внутри слова остается.

Слова ищем регулярным выражением \w+(?:-\w+)* через re.findall(). Часть \w+ берет обычное слово, а группа (?:-\w+)* разрешает дефис между частями, поэтому по-настоящему остается одним токеном. Числа тоже считаются словами, а эмодзи, знаки препинания и длинное тире работают как разделители и пропадают. Если на входе не строка, бросаем TypeError.
